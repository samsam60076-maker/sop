門市 POS 從頭來過（請只看這張）

先前在 GitHub 建的 -sop、-SOP1 可以不理，也不要再開第三個空盒子。
那些裡面只有開店.bat，Render 不能用。

========================================
第一步：讓程式進 GitHub（不要自己建空庫）
========================================

1. 回到 Cursor 這一頁對話（不是 GitHub 網站）。
2. 按「Create repo」（建立儲存庫）。
3. 帳號選 samsam60076-maker。
4. 名稱打英文：menshipos
5. 選公開，按建立。
6. 等它跑完。打開 GitHub 時，應該看到很多檔案
   （package.json、render.yaml、app、components），
   不能只有一個開店.bat。

找不到 Create repo 時，才用下面「備案」。

========================================
第二步：放到 Render（每天用的網址）
========================================

1. 打開已經開著的 Render Dashboard。
2. 用 GitHub 帳號登入（同一個 samsam60076-maker）。
3. 按 New + → Blueprint。
4. 選 menshipos，連上去。
5. 按 Apply / Create。
6. 等到服務變綠色 Live。
7. 複製網址，會像 https://men-shi-pos.onrender.com
8. 把這一條存書籤、放到手機桌面。以後每天點它。

免費方案閒置後第一次打開可能要等半分鐘。
網址本身不會因聊天關掉而失效。

若 Blueprint 找不到：New + → Web Service，連同一個 GitHub。
Build Command：npm ci && npm run build
Start Command：npm start
Instance type：Free
Region：Singapore

========================================
備案：手動上傳（只有找不到 Create repo 才做）
========================================

1. 下載壓縮檔，解壓縮。
2. 打開檔案總管 → 下載 → 找到黃色資料夾 men-shi-pos。
3. 把「整個資料夾」拖進 GitHub 白框。不要只拖開店.bat。
4. 按綠色提交。確認有 package.json、render.yaml。
5. 再做上面第二步 Render。

========================================
店裡那台 Windows
========================================

解壓縮後拖到桌面，改名叫「門市POS」，雙擊「開店.bat」。
書籤只存：http://127.0.0.1:3847
這條只這台電腦能開。

========================================
資料
========================================

沒有帳號密碼。資料在「那支手機／那台電腦的瀏覽器」。
換手機請先到「備份門市資料」匯出，再到新的匯入。

# 門市 POS（巷口商行／加盟店）

進貨、銷貨、庫存一體的收銀與進銷存系統。總部可切換西螺、斗南、虎尾、斗六、南投、民雄、北港，每間門市各一本帳。

資料存在這台電腦的瀏覽器。換網址、換電腦或清瀏覽器就會變成空店。請到 **備份門市資料** 按「匯出本店備份」。每台電腦各自備份這一間，別台電腦匯不進去七店合檔。

## 功能

- **總商品列表**：總部一份，七間門市同一套名稱、售價、批價、分類。在任一間新增或修改，其他六間一起變。庫存數量仍各店分開，收銀商品卡片看得到。可勾選多項一次刪除。列表沒有數量。
- **櫃位與作業說明**：七間同一套。在西螺新增櫃位或改說明，斗南、虎尾等一起變。店名仍各店自己的。
- **進貨**：可連續點選或打名稱加入多項，最後一次確認入庫。打錯可刪，總表同一張單會一起消失。
- **總表**：選年月日看當日營收、當月營收、當月進貨售價／批價、毛利與毛利率。銷貨明細列出每一張單的每一項（與銷貨頁同一批資料）。列印本店會印出這些明細。這裡刪的，收銀／銷貨／進貨／支出也不再出現。
- **支出表**：記當月房租、水電。打錯可刪，總表同一筆會一起消失。
- **盤點單**：先選盤點日期再開單，填實盤後入帳。日期可之後再改；列印與總表依這一天歸帳。每一項可註明當時在哪一櫃。列印可選小字／中字、一欄／兩欄、全部或只印畫面上的。
- **收銀**：瑕疵在購物車改售價並按「瑕疵」。每項可自己打備註。退費自己填金額並寫備註。本日已入帳的銷貨／退費可點開看每一項明細，也可刪，總表一起拿掉。
- **銷貨**：客人退貨點開單據填數量；商品不好可不回庫。打錯可刪整張單（連退貨），總表不再留紀錄。
- **收銀／銷貨**：打名稱即可加入，可用「茶葉蛋*2」。平常販售預設備註「正常販售」。
- **備份門市資料**：切換門市、匯出／匯入本店備份。每台電腦只備份眼前這一間。

## 本機執行

公司電腦（Windows）把**裡面有 `開店.bat` 的那一整包**放到桌面，資料夾可改名叫 `門市POS`（例如 `桌面\門市POS\開店.bat`）。只做一次：

1. 第一次：若尚未安裝 Node.js，到 [nodejs.org](https://nodejs.org/zh-tw/download) 下載左邊綠色 LTS。安裝時不要勾「自動安裝必要工具」。
2. 雙擊 `開店.bat`。第一次會等幾分鐘，並自動加入 Windows 開機啟動，桌面也會出現「門市 POS」。
3. 以後開機點桌面的 **門市 POS**，或書籤只存 `http://127.0.0.1:3847`。不要存聊天裡的臨時網址。
4. 開機後也會自動開店（黑畫面縮在工作列，不要關）。若不要自動開，雙擊 `取消開機啟動.bat`。只要補桌面捷徑：雙擊 `放到桌面.bat`。

```bash
npm install
npm run dev
```

瀏覽器開啟 [http://127.0.0.1:3847](http://127.0.0.1:3847)。

聊天裡的臨時網址隔夜或重開後會失效。那不是店壞了，是門被關掉。

**每天固定用：**

- 手機／別店：把專案放到 [Render](https://dashboard.render.com)（Blueprint 會讀 `render.yaml`），書籤存 `https://某某.onrender.com`。
- 店裡電腦：書籤只存 `http://127.0.0.1:3847`，或點桌面「門市 POS」。

不要存聊天裡的臨時網址。沒有登入帳號。資料在各自瀏覽器。換手機或清資料會變空店，請先在電腦 **備份門市資料** 匯出備份，再到手機匯入。

```bash
npm run build
npm start
```

## 使用方式

1. 到 **總商品** 建名稱、售價、批價。分類可自訂。整理舊資料時可在表格改多項再一次確定更改，或勾選多項一次刪除。
2. **進貨** 選日期，連續點商品或打「茶葉蛋*10，純水*6」加入多項，改數量後再按確認入庫。
3. **收銀** 先選年月日再結帳，只收現金。員工購買切「員工購買」，全部以批價計。突然改價：在購物車改售價，備註自己打。瑕疵按「瑕疵」。退費按「退費」，自己打金額並寫備註。打完可點本日紀錄看明細；打錯按刪除。
4. **總表** 看當日營收、當月營收、退貨、支出與庫存明細。銷貨明細是收銀／銷貨打的每一張單，點「列印本店」會印出每一項。任一頁刪除，這裡都不會再出現。
5. **銷貨** 點開單據辦理退貨；商品不好不要勾回庫。打錯刪整張單，總表同一筆會消失。
6. **支出表** 記當月房租、水電等細項。打錯可刪。
7. 到 **盤點** 先選盤點日期再開單，填實盤，並註明當時在哪一櫃。要抽查冰箱可列印抽查表。
8. 最上面一排切換七間門市。每間各一本帳。各店電腦到 **備份門市資料** 匯出本店備份即可。

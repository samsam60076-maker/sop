這是門市 POS。做完下面這些，以後開電腦就能用。

【哪個資料夾】

整包程式，裡面要看得到這些檔：
  開店.bat
  放到桌面.bat
  開機啟動.vbs

把「整包」放到這台店的電腦桌面，資料夾可改名叫「門市POS」。
路徑會像：桌面\門市POS\開店.bat
不要只拷一個檔，也不要放隨身碟。
不要把聊天裡的網址當資料夾。

【只做一次】

1. Node.js 若已裝好，不要再打開安裝程式。
   若還沒裝：https://nodejs.org/zh-tw 下載左邊綠色 LTS。
   安裝時若有「自動安裝必要工具 / Tools for Native Modules」，把勾取消。
   出現黑畫面寫「請按任意鍵繼續」：不要按，按 X 關掉。
2. 打開桌面的「門市POS」，雙擊「開店.bat」。第一次會等幾分鐘。
   跑完會自動加入 Windows 開機啟動，桌面也會出現「門市 POS」捷徑。
3. 書籤只存這一條：
   http://127.0.0.1:3847

【以後每天】

開電腦 → 點桌面的「門市 POS」（或等幾秒再點書籤）。
不要關那個黑畫面，關掉店就關了。
不要用聊天裡的網址當書籤。

【固定網址・每天用】

聊天裡 trycloudflare 那條不能當每天的門。要固定，選一種：

A. 店裡那台電腦（本機）
   桌面捷徑「門市 POS」或書籤只存：
   http://127.0.0.1:3847
   開機點捷徑就能收銀。這條只這台電腦能開。

B. 手機、別店（Render 固定網址）
   先前自己建的空 GitHub（只有開店.bat）不要用。
   1. 這個對話頁按 Create repo，名稱打 menshipos。
   2. 到 https://dashboard.render.com 用 GitHub 登入。
   3. New + → Blueprint，選 menshipos。
   4. 等到綠色 Live，把 https://某某.onrender.com 存書籤。

沒有帳號密碼。資料存在「那支手機／那台電腦的瀏覽器」。
換手機或清資料會變空店，請先「備份門市資料」匯出，再到新的匯入。

【不要自動開】

雙擊「取消開機啟動.bat」。
只要補桌面捷徑：雙擊「放到桌面.bat」。
